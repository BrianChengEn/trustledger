## [2026/10/17 18:24] — 工作區同期變動時覆寫共用檔案

- 觀察：另一流程於 Nessie 問答期間加入已追蹤的 TrustLedger 骨架；以先前空工作區的假設建立根 AGENTS 與文件索引，覆寫了兩個既有檔案。
- 原因：寫入共用路徑前未重新查核工作區；新增檔案操作也可能替換已存在內容。
- 修正：從 Git `636ab15` 恢復兩份原始追蹤內容，確認完整保留，只附加連結；新雙語索引移至 `docs/v0.0.0/`。以 Q020 確認整合範圍，不自行假設授權，保留無關工作樹變更。
- 預防：長時間問答或工作區外部變動後，寫入共用檔案前重新檢查存在性及 Git 狀態。提案限制在版本目錄，保留既有專案指引、owner、契約與 CI。

## [2026/10/17 18:24] — 資料交付後未接續問題集

- 觀察：產生合成資料後，回覆僅報告資料工作完成，未提出下一個仍待釐清的流程問題，使用者另行要求繼續。
- 原因：將輔助交付誤當成持續進行的需求問答停止點。
- 修正：依 D004 繼續釐清資料整合、timestamp 比較、儲存失敗及匯入重跑，再草擬設計。
- 預防：支線工作結束後恢復原始目標，找出下一項關鍵未決選擇；完成資料集不代表設計問題閘門已通過。

## [2026/10/17 18:59] — 匯入前置查證漏查標記漂移

- 觀察：獨立審查重現其他欄位改動時會重複標記，以及先建立大量客戶後才發現 probe 交易改動。
- 原因：標記偵測重用完整 payload 相等檢查，完整匯入前只查確認旗標與餘額。
- 修正：任何未追蹤標記皆停止；查證必須只有一筆標記且 payload 相符；完整寫入前讀回 probe 八筆。回歸測試先失敗後通過，同一審查者在真實續跑前確認兩項修正。
- 預防：區分紀錄身分與 payload 相等，完整檢查寫入關卡的所有依賴。
